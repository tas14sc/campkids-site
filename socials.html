# The Camp Kids — Website Static site for [thecampkids.com](https://www.thecampkids.com). Deployed via Railway from this GitHub repo. ## Pages - `index.html` — Home: hero with group illustration, Debby quote + classroom photo collage - `characters.html` — 12 character cards, each opens a modal with their bio - `concepts.html` — Big EQ Treasure Map with 4 clickable islands + 6 Camp Kids Connection flyer cards - `camps.html` — Summer camp flyer + embedded Google Form signup - `store.html` — The Camp Kids Outpost (coming soon) - `socials.html` — Instagram + email contact with Camper Kallen ## Branding - **Fonts:** Boogaloo (headlines), Nunito (body), Lora italic (red accents) - **Palette:** Forest green, parchment cream, accent red, tan - **Atmosphere:** Stars, fireflies, tree silhouettes across all pages ## Structure ``` campkids-site/ ├── index.html ├── characters.html ├── concepts.html ├── camps.html ├── store.html ├── socials.html ├── styles.css ← shared stylesheet (1700+ lines, all pages read from it) ├── scripts.js ← shared JS (atmosphere, mobile nav, 3 modal systems) ├── package.json ├── railway.json ├── .gitignore ├── README.md ├── characters/ ← 12 character SVGs ├── concepts/ ← 5 concept SVGs (currently unused on site, saved for future) ├── connections/ ← 6 Camp Kids Connection flyer PNGs └── misc/ ← patch badge, group scene, treasure map, classroom photo, camps flyer ``` ## Deploy Push to `main` → Railway auto-redeploys in ~60 seconds. ## Local preview ```bash npx serve . ```
